**一句话概括**

当前方案不是“inferCNV 阳性细胞直接判恶性”，而是：

**先确认上皮身份 → 每个样本单独运行 inferCNV → 依据 cluster 层连续大片段 CNV 热图分级 → 再联合 CopyKAT、肿瘤/正常上皮程序和组织来源确定恶性标签。**

详见[主线方案 F1.6](D:\服务器_胃癌线粒体亚群\胃癌MLMOD亚群主线研究方案.txt:315)。

**1. 分析对象**

只分析 F1.5 中已经确认的高/中置信上皮细胞：

- 排除明确 mixed、doublet 和污染 cluster。
- 不在全部细胞中直接找恶性细胞。
- inferCNV 和 CopyKAT 均使用 `RNA raw counts`。
- SCT residual、Harmony、LogNormalize 不作为 CNV 输入。

**2. 参考细胞**

每个样本分别选择参考细胞：

1. 优先使用同一样本高/中置信 T/NK 细胞。
2. 少于 50 个时加入同一样本 B/Plasma。
3. 仍不足时才使用跨样本汇总的 T/NK、B/Plasma，最多取约 500 个。
4. 正常胃上皮不作为主参考，以免其中混入拷贝数异常或状态差异。

运行前还要检查参考细胞的 ambient RNA 风险。少数污染参考细胞优先删除或替换；不能只校正参考细胞而不校正观察细胞。[参考细胞方案](D:\服务器_胃癌线粒体亚群\胃癌MLMOD亚群主线研究方案.txt:318)

**3. inferCNV 设置**

当前登记参数为：

- 按 `sample_id` 分开运行。
- 观察单位：`sample_id × epithelial_cluster_id`。
- GRCh38 gene order，仅分析 chr1–chr22。
- `cutoff = 0.1`
- `denoise = TRUE`
- `HMM = FALSE`
- `num_threads = 4`
- 最少参考细胞数：50。

`HMM=FALSE`意味着主分析关注相对于参考细胞的连续大片段表达偏移，而不是让 inferCNV 的 HMM 自动输出离散 CNV call。[参数配置](D:\服务器_胃癌线粒体亚群\scripts\F1_single_cell\F1_config.R:81)

**4. inferCNV 如何判读**

主要看样本内热图是否出现跨越较长染色体区域、方向一致的 gain/loss 模式。

不会用一个逐细胞分数机械判恶性。脚本另外计算：

- 每个细胞相对参考中心的 `infercnv_cell_burden`。
- 参考细胞 burden 的 P95。
- 每个上皮 cluster 中高于参考 P95 的细胞比例。

这些指标只帮助定位和解释热图，不能自动生成恶性标签。最终由研究者将每个 `sample × epithelial cluster` 的 inferCNV 证据评为：

- `strong`
- `weak`
- `absent`
- `not_evaluable`

然后再进入联合判定。[热图审核步骤](D:\服务器_胃癌线粒体亚群\scripts\F1_single_cell\F1_06_malignancy_inference.R:345)

**5. 最终恶性标签**

| 标签 | 当前判定逻辑 | 后续用途 |
|---|---|---|
| `malignant_high_confidence` | inferCNV cluster 为 strong，且该细胞 CopyKAT 为 aneuploid | 进入 06a 和 06b |
| `malignant_probable_infercnv` | inferCNV strong；CopyKAT diploid/uncalled；来自肿瘤或转移样本，并有肿瘤上皮程序 | 进入 06a |
| `malignant_probable_copykat` | CopyKAT aneuploid；inferCNV 弱、阴性或不可评估；具有肿瘤来源和肿瘤上皮程序 | 进入 06a |
| `non_malignant_epithelial` | inferCNV 无连续大片段异常、CopyKAT diploid、正常上皮程序明确 | 作为正常上皮对照 |
| `epithelial_uncertain` | 两种方法冲突、均弱或无法评价 | 不进入 F2 主分析 |
| `exclude_contamination_or_doublet` | 污染、混合谱系或高置信 doublet | 排除 |

因此：

- `06a`：高置信＋两类 probable 恶性细胞。
- `06b`：只包含 inferCNV 和 CopyKAT 同时支持的高置信恶性细胞。
- 组织来源只能提供支持，不能直接把肿瘤或腹膜转移来源细胞判为恶性。

**上皮程序如何确定**

修改前，这两个字段确实只是人工审核表中的空白布尔项，定义不够闭合。现在明确为辅助性生物学判断，不另外发明“肿瘤程序评分”：

- **正常样上皮程序**：出现成套、可解释的胃上皮分化特征，如 pit、mucous neck、chief、enteroendocrine 等，并结合 Normal_Gastric 中的参考表达和样本分布判断。单个 `TFF`、`MUC`、`REG` 不够；intestinal-like 也可能代表化生或肿瘤，不能单独判正常。
- **肿瘤样上皮程序**：sample × cluster 中存在成套的异常上皮转录特征，结合 cluster marker、相对正常上皮的差异和肿瘤样本支持判断；不能仅凭组织来源、高 MT、增殖、一般应激、ambient RNA 或单个“癌基因”认定。
- 审核模板现在会直接带入 F1.5 的 `top_markers`、组织构成和上皮亚型，供上述判断使用。
- MLMOD、预后和F2结果不参与恶性判定，避免循环定义。

这里的关键边界是：正常分化程序可残留在恶性细胞中，所以它本身不等于良性；肿瘤来源也不等于恶性。最终仍以 inferCNV/CopyKAT 为主，程序证据只帮助处理单方法支持和双阴性情形。

[837] Codex | 2026-07-23 22:27:26 Asia/Shanghai
**核心结论**

不能简单理解成“表达正常 marker 就是正常细胞，表达癌 marker 就是癌细胞”。正确做法分两层：

1. **胃上皮谱系 marker**回答“它像哪一种胃上皮细胞”。
2. **与同谱系正常细胞比较**回答“这种表达状态是否已经明显异常”。

原研究也是比较肿瘤上皮与其对应的正常上皮状态，并结合肿瘤相关表达程序和CNV，而不是靠一个万能癌细胞 marker。[Kumar等，Cancer Discovery 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9394383/)

**正常胃上皮 Marker**

| 类型 | 核心 marker | 辅助 marker |
|---|---|---|
| 广义上皮身份 | `EPCAM, KRT8, KRT18, KRT19, CDH1` | 只证明是上皮，不证明正常或恶性 |
| 胃小凹/表面黏液细胞 | `MUC5AC, TFF1` | `GKN1, GKN2` |
| 黏液颈细胞 | `MUC6, TFF2` | 需注意也可能代表SPEM化生 |
| 主细胞 | `LIPF, PGA3, PGC` | `PGA4, PGA5` |
| 壁细胞 | `ATP4A, ATP4B` | `CLIC6, CBLIF/GIF` |
| 胃肠内分泌细胞 | `CHGA, CHGB` | `TPH1, GAST, SST, GHRL` |
| 肠型/肠化生样 | `REG4, TFF3` | `CDX1, CDX2, MUC2, APOA4, VIL1` |

肠型程序不能直接算“正常”。原研究将`REG4/TFF3`阳性细胞解释为肠型或肠化生相关状态，它既可能出现在癌前病变，也可能出现在癌细胞中。

当前项目的 [cell_type_marker_panel.tsv](D:/服务器_胃癌线粒体亚群/data/metadata/cell_type_marker_panel.tsv) 已经覆盖大部分类型，但缺少壁细胞；建议补入`ATP4A/ATP4B`，并把`GKN1/GKN2、PGA4/PGA5、CHGB`作为辅助 marker。

**怎样判定“正常样程序”**

`normal_program_support = TRUE`不能只因为出现了`MUC5AC`或`LIPF`。需要同时看到：

1. 有明确上皮身份。
2. 至少有一套完整、相互协调的胃上皮分化程序。
3. 与本数据集`Normal_Gastric`中相同谱系的细胞整体相似。
4. 没有成套的异常表达变化。
5. 不是少数细胞、ambient RNA或单个高表达基因造成。

胃癌细胞也可能保留主细胞或黏液细胞分化特征，所以“有正常谱系 marker”不等于“非恶性”。已有胃癌研究甚至发现保留`LIPF/PGC/PGA3`的主细胞样恶性亚型。[Gut原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7873416/)

**怎样判定“肿瘤样程序”**

不建立一份固定的“癌细胞阳性 marker 清单”。对每个`sample × epithelial cluster`，与`Normal_Gastric`中的同谱系细胞比较，主要看：

- 正常分泌或消化功能程序是否成套减弱。
- 是否出现多基因组成的肿瘤相关上皮程序。
- 是否出现异常去分化、再生、EMT或细胞运动程序。
- 变化是否存在于一批细胞，而不是单个基因或少数细胞。

可以重点观察但不能单独硬判的候选包括：

- `CEACAM5, CEACAM6, CLDN4, KRT7, KRT17, MMP7`
- `SOX9, OLFM4`
- 原研究检查过的`EGFR, MET, CCND1, KRAS`

其中`MKI67/TOP2A`增殖、缺氧、应激、高线粒体、凋亡、肠化生或组织来自肿瘤，都**不能单独算肿瘤样证据**。原研究也观察到肿瘤上皮的EMT、运动及癌相关程序升高，但仍用CNV进行补强。[Kumar等原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9394383/)

**用于F1.6的最终规则**

- inferCNV强支持＋CopyKAT非整倍体：RNA层面高置信恶性，不要求额外癌 marker 投票。
- 只有一种CNV方法支持：必须有肿瘤样程序，而且没有明确正常样程序，才列为可能恶性。
- 两种CNV方法均不支持：只有正常样程序明确且无肿瘤样程序，才列为非恶性上皮。
- 正常样和肿瘤样同时存在，或两者都不明确：保留为`epithelial_uncertain`。

这套规则的重点是：**marker负责说明分化身份，同谱系正常比较负责发现异常，inferCNV和CopyKAT负责主要恶性证据。**

**教程评价**

这份教程适合学习 Seurat 操作顺序，但不能原样作为本项目方法学依据：

- QC部分采用 `nFeature 300–7000`、`mt<10%`、`HB<3%`、删除最高3% UMI，并提出反复调整到“最佳结果”。作为教学示例可以，但论文中容易被质疑为结果导向调参。[教程QC段](</D:/散装生信视频教程的R代码_注释版/01_单细胞视频合集代码/15-25. 单细胞标准流程SeuratV5全流程.R:73>)
- DoubletFinder在合并后的上皮对象上运行，2436个细胞却直接使用7.5%预期率，最后只删除cluster 2中的Doublet，其他cluster的Doublet继续保留。这不是规范用法。DoubletFinder原则上应按独立建库运行，`pK`由数据决定，预期双细胞率应对应实际捕获细胞数。[DoubletFinder官方说明](https://github.com/chris-mcginnis-ucsf/DoubletFinder)
- 教程回归了 `mt_percent`。一般研究中可以讨论，但本项目研究线粒体相关状态，回归它可能削弱真实生物学信号；当前“不回归mt”的决定更合适。[SCTransform文档](https://satijalab.org/seurat/reference/sctransform)
- 教程把 inferCNV 的 `HMM=FALSE`解释成“关闭背景降噪且不影响结果”，这是事实性错误。`denoise`负责降噪；HMM负责进一步预测CNV状态。我们可以用`HMM=FALSE`观察连续大片段模式，但不能声称它不影响结果类型。[inferCNV官方说明](https://github.com/broadinstitute/infercnv/wiki/Running-InferCNV)
- 教程没有处理ambient RNA，也没有真正闭合恶性细胞联合判定。

[899] Codex | 2026-07-29 00:48:23 Asia/Shanghai
**结论：可以，而且更适合本项目。**

高质量研究并不是一律打开 inferCNV 的内部 subclustering，而是根据研究问题选择：

- **只鉴定恶性细胞**：通常不需要内部 subclustering。重点是看上皮细胞相对于正常参考细胞，是否存在稳定、连续的大片段染色体增益或缺失。
- **研究肿瘤亚克隆和克隆进化**：才需要 subclustering，并且必须调整分辨率、检查亚群大小和验证 CNV 差异。高水平研究也通常是在已经鉴定恶性细胞后，才使用 subcluster 方法研究克隆结构。例如这篇 Nature Communications 研究明确把 subclustering 用于“探索亚克隆结构”，而不是最初的恶性鉴定。[Nature Communications 研究](https://www.nature.com/articles/s41467-024-52980-5)

inferCNV 官方特别提醒，subclustering 分辨率常需调整，否则容易把一个连续群体过度拆成很多小群。[inferCNV 官方仓库](https://github.com/broadinstitute/infercnv) 因此，如果论文并不讨论克隆演化，开启它反而会增加不必要的不确定性。

**本项目建议这样处理：**

1. 每个样本单独运行 inferCNV，使用同一样本的可靠免疫细胞作为正常参考。
2. 显式设置 `analysis_mode="samples"`，不使用 inferCNV 内部 Leiden subclustering。
3. 保留已有的 Seurat 上皮细胞簇作为观察和汇总单位。
4. 主要判断染色体级或大片段 CNV 模式，而不是零碎的小区域变化。
5. 结合 inferCNV、可靠的 CopyKAT结果、样本来源和上皮细胞身份区分恶性、可能恶性、非恶性及不确定细胞。

**结论：两种顺序都合规，但对异质性较高的肿瘤组织，更推荐“先粗聚类/粗注释，再运行 DecontX”。**

更规范、便于解释的顺序通常是：

1. 完成基础QC，排除明显低质量细胞。
2. 按建库样本运行双细胞识别并删除主判双细胞。
3. 使用未校正raw counts进行一次粗粒度聚类。
4. 根据成套marker确定上皮、T/NK、B/浆细胞、髓系、成纤维、内皮等大谱系。
5. 每个样本分别运行DecontX，把这些粗谱系标签作为`z`。

7. 只有污染确实改变关键结论且校正没有明显误伤时，才考虑让corrected矩阵进入相应分析。

这里使用的只能是**粗谱系标签**，不能使用精细上皮亚群、MLMOD分数、恶性标签或预后结果，否则容易形成循环判断。

对本项目，建议采用干性方案的顺序：

`固定QC → scDblFinder → raw counts第一轮粗聚类和大类注释 → 每样本DecontX（使用粗谱系标签）→ raw/corrected比较`

# 二、最推荐的总体结构

## 第一部分：构建mitoxyperilysis转录signature

直接使用原始Cell研究公开的 **GSE235046**。它包含5组、每组3个重复：

* Media；
* LPS；
* carbon starvation，CS；
* LPS＋CS；
* LPS＋CS＋Torin-1。

RNA-seq是在刺激9小时后获得的；原始论文证明LPS＋CS诱导BAX/BAK1/BID依赖的线粒体氧化损伤，并由mTORC2促进线粒体在质膜处滞留和最终膜裂解。GEO提供原始计数矩阵和SRA数据。([[国家生物技术信息中心](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE235046&utm_source=chatgpt.com)][1])

### 1. 用析因模型找“协同响应”

不要简单做：

> LPS＋CS vs Media差异基因。

因为这会混入大量普通LPS炎症和饥饿反应。

应该对原始count矩阵使用：

[
\text{expression}\sim \text{LPS}+\text{CS}+\text{LPS:CS}
]

重点检验 `LPS:CS` 交互项。

保留同时满足以下逻辑的基因：

* LPS和CS联合效应超过两个单独处理的简单相加；
* LPS＋CS相对于Media、LPS和CS方向一致；
* 有足够效应量；
* 在重复重抽样中方向稳定。

由于每组只有3个样本，**不适合在这里使用WGCNA、深度学习或复杂机器学习**。应使用透明的DESeq2析因模型、效应量和bootstrap稳定性筛选。

### 2. 加入Torin-1救援方向

对于每个协同响应基因，进一步观察：

> LPS＋CS＋Torin-1 vs LPS＋CS。

若某基因在LPS＋CS中升高，加入Torin-1后下降；或者在LPS＋CS中降低，加入Torin-1后回升，可以认为它与mTOR依赖的执行过程更接近。

最终拆成至少两套模块：

| 模块                   | 定义                       | 生物学解释                |
| -------------------- | ------------------------ | -------------------- |
| MP-execution-up/down | LPS＋CS协同改变，并被Torin-1反向恢复 | 更接近mTORC2依赖的膜接触/执行程序 |
| IIAMD-stress-up/down | LPS＋CS协同改变，但Torin-1不能恢复  | 更接近上游氧化、炎症和代谢应激      |

原始研究表明，Torin-1能够阻止膜裂解并恢复细胞骨架活动，但不会恢复谷胱甘肽下降和整体氧化应激，因此这两种模块在机制上本来就应该分开。([[PubMed Central (PMC)](https://pmc.ncbi.nlm.nih.gov/articles/PMC12875127/?utm_source=chatgpt.com)][2])

### 3. 转成人类基因集

只保留明确的一对一鼠—人同源基因，分别形成：

* `MP_execution_up`
* `MP_execution_down`
* `IIAMD_stress_up`
* `IIAMD_stress_down`

评分时使用：

> up模块得分 − down模块得分。

不要把上下调基因无方向地放在一起平均。

### 4. 做稳定性筛选

建议进行分组内bootstrap或leave-one-replicate-out：

* 每次重新拟合模型；
* 记录基因效应方向；
* 记录是否重复通过阈值；
* 将≥70%或80%重抽样中方向一致的基因纳入核心集；
* 其余进入扩展集。

最后可以发布：

* **Core signature**：高度稳定、数量较少；
* **Extended signature**：用于通路探索；
* 每个基因的交互效应、Torin救援效应、稳定频率和证据等级。

这张完整表本身就是文章的重要结果。

# 三、第二部分：证明它不是普通炎症或细胞死亡评分

这是文章能否超过现有两篇研究的关键。

## 1. 内部验证

在GSE235046中应看到：

* LPS＋CS最高；
* Media、LPS、CS较低；
* Torin-1显著降低execution评分；
* stress评分可能不被Torin-1完全降低。

这会形成符合原始机制的“双模块解耦”。

## 2. 其他死亡方式数据集作为负对照

可以使用公开数据测试特异性。

例如 **GSE221999** 在同一种L929细胞背景中包含：

* 未处理；
* 凋亡；
* 坏死性凋亡；
* 铁死亡。

它特别适合作为跨死亡方式的比较数据。([[国家生物技术信息中心](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE221999&utm_source=chatgpt.com)][3])

**GSE235201**则建立了铁死亡—凋亡连续梯度，并利用多套外部数据筛选两种死亡方式的特异转录标志物，可以作为另一套独立benchmark。([[国家生物技术信息中心](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE235201&utm_source=chatgpt.com)][4])

需要比较：

* mitoxyperilysis execution score；
* ferroptosis；
* apoptosis；
* necroptosis；
* ROS response；
* TNF/NF-κB；
* starvation；
* hypoxia；
* interferon response。

理想结果不是“完全没有重叠”，而是：

> MP-execution模块在LPS＋CS中最明显，且不能被普通氧化应激、铁死亡或凋亡评分完全解释。

可以用多变量模型验证：

[
MP\ score \sim ROS + TNF + starvation + ferroptosis + apoptosis
]

看MP评分是否还保留独立的信息。

## 3. mTORC2外部支持

还可以使用：

* **GSE167010**：J774.1巨噬细胞样细胞中的Rictor-KO及Torin-1转录组；
* **GSE243343**：Rictor敲除的肠上皮细胞转录组。

它们不是mitoxyperilysis诱导数据，不能当作直接验证，但可以检验你的Torin可逆模块是否在独立的mTORC2扰动条件下出现一致方向。([[国家生物技术信息中心](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE243343&utm_source=chatgpt.com)][5])

证据层次应明确写为：

* GSE235046：直接发现数据；
* Rictor/Torin数据：机制支持；
* 其他死亡数据：特异性benchmark；
* 癌症数据：疾病映射。

# 四、第三部分：先泛癌筛选，再决定是否重点做胃癌

不要先默认胃癌一定最适合。可以先在你原本考虑的癌种中做快速筛选：

* STAD；
* CRC；
* PAAD；
* ESCA；
* LIHC。

筛选标准包括：

1. TCGA中execution评分是否有稳定变异；
2. 在恶性细胞而不只是在巨噬细胞中是否可检测；
3. 肿瘤恶性细胞相对正常上皮是否升高；
4. 是否在多个患者中复现；
5. 是否有至少两个单细胞数据集；
6. 是否有空间转录组；
7. 是否有独立bulk或治疗响应队列。

由于结直肠癌和黑色素瘤已经有相关论文，**胃癌如果信号和数据条件合适，竞争位置反而更好**。现有黑色素瘤文章使用单细胞MRS相关前150基因建立101种机器学习模型；结直肠癌文章使用bulk GSVA、预后筛选和101种模型。([[PubMed Central (PMC)](https://pmc.ncbi.nlm.nih.gov/articles/PMC13189447/?utm_source=chatgpt.com)][6])

你的设计不应重复它们，而应强调：

> signature是从独立的机制扰动数据预先建立的，癌症数据只负责验证和解释，不参与重新定义signature。

# 五、如果最终选择胃癌，主分析这样做

## 1. 恶性上皮细胞内部连续评分

在至少两个独立胃癌单细胞队列中：

* 识别恶性上皮细胞；
* 分别计算execution和stress评分；
* 在同一细胞类型、同一患者内部比较；
* 不机械地把所有细胞按全局前25%划为MP-high。

主要统计单位应是患者，而不是把成千上万个细胞当作独立重复。

可以用：

* 患者级pseudobulk；
* 或混合效应模型；
* leave-one-patient-out验证。

## 2. 排除混杂

必须检查评分是否只是以下因素的替代：

* nFeature/nCount；
* percent.mt；
* 细胞周期；
* 普通缺氧；
* TNF/IFN炎症；
* ROS；
* ferroptosis；
* 凋亡；
* EMT；
* 肿瘤纯度和患者来源。

可以使用多变量模型和残差评分，而不是仅凭相关热图。

## 3. 找到真正相关的恶性细胞程序

不要急着找“hub genes”。更适合先问：

* execution评分与哪些cNMF程序或共表达模块相关；
* 是否跨患者复现；
* 是否与代谢限制、线粒体损伤、细胞骨架和膜重塑一致；
* 是否存在“应激高但execution低”的抵抗状态。

后一个比较特别有价值：

> 同样有炎症和氧化应激，为什么部分细胞没有进入mTORC2依赖的执行程序？

这可能找到潜在的mitoxyperilysis逃逸机制。

## 4. 空间生态位

空间转录组不要只画几个FeaturePlot，而应回答：

* execution高的肿瘤区域是否邻近TNF高表达的巨噬细胞；
* 是否与缺氧、低营养、坏死边缘共定位；
* 是否与RICTOR/mTORC2、低RhoA/细胞骨架状态相伴；
* 是否存在特定成纤维细胞或髓系细胞生态位；
* 这种共定位能否在多个切片复现。

原始Cell研究证明，先天免疫刺激与代谢限制联合可在B16肿瘤中引起mTORC2依赖的坏死和肿瘤缩小，因此癌症空间生态位具有明确的原始机制依据。([[PubMed Central (PMC)](https://pmc.ncbi.nlm.nih.gov/articles/PMC12875127/?utm_source=chatgpt.com)][2])

CellChat或NicheNet只用于回答：

> 哪些免疫细胞可能向execution高的恶性细胞提供TNF或其他先天免疫信号？

而不是为了增加图数量。

# 六、临床分析不要再做传统“101种机器学习”

建议把预先固定的signature直接用于：

* TCGA-STAD；
* 至少1–2个独立GEO队列；
* 有条件时加入化疗或免疫治疗队列。

主要检验：

* 与分期、转移、复发、治疗响应的关系；
* 多因素Cox中是否独立；
* 在肿瘤纯度、免疫和间质校正后是否仍成立；
* execution和stress两种评分是否具有不同临床意义。

例如可能出现：

* stress高、execution高：正在进入膜裂解相关状态；
* stress高、execution低：具有应激但逃逸执行，可能更加耐受；
* 两者都低：缺乏相应免疫—代谢刺激。

这种**二维状态分类**比简单的高低风险模型更有生物学价值。

机器学习最多作为次要分析：

* 用固定signature预测治疗反应；
* 嵌套交叉验证；
* 完整独立外部队列；
* 不重新根据预后选择一批“mitoxyperilysis基因”。

# 七、纯生信还能怎样加强“机制”

可以整合公共扰动数据：

* RICTOR敲除或Torin-1处理后，execution评分是否下降；
* 候选基因敲除的LINCS/CMap转录响应是否使评分逆转；
* DepMap中候选基因依赖性是否集中在execution高的胃癌细胞系；
* 候选基因是否与RICTOR依赖、氧化应激脆弱性或营养依赖相关。

这样只能称为：

> 计算支持的候选调控因子。

不能称为已经证明的上游调控基因，但比单纯相关性和“hub gene”更强。

# 九、论文中的措辞边界

纯生信情况下可以说：

* mitoxyperilysis-derived signature；
* rescue-aware mitoxyperilysis transcriptional program；
* mitoxyperilysis-aligned malignant-cell state；
* putative susceptibility/escape program；
* computationally prioritized regulators。

不要说：

* 证明胃癌细胞发生了mitoxyperilysis；
* 建立了标准或金标准基因集；
* 发现某基因调控mitoxyperilysis；
* MP-high细胞就是正在发生膜裂解的细胞；
* 模型具有临床应用价值。

因为公共转录组不能直接观察线粒体—质膜接触和膜裂解。

**结论**

这份回答的核心思路值得吸收，但不能整套照搬。我们的最终选择是：

> 保持胃癌主线，以原作者差异分析标准建立主基因集，再用协同效应、Torin-1 救援和外部死亡方式数据增加解释力，而不把项目扩展成泛癌基因集方法学工程。

**F2 基因集构建最终路线**

1. **发现数据**

使用 GSE235046：Media、LPS、CS、LPS＋CS、LPS＋CS＋Torin-1，每组3个重复。主分析仍以 SRA 原始数据重新定量后进入 DESeq2。[GEO记录](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE235046)

2. **主小鼠基因集**

主基因集只纳入同时满足以下三个比较的上调基因：

- LPS＋CS vs Media；
- LPS＋CS vs LPS；
- LPS＋CS vs CS；
- 三个比较均为 `log2FC > 1`、BH校正后 `FDR < 0.05`。

这正是原作者定义“共同上调基因”的方法，不是我们临时自创的标准。[原论文方法全文](https://api.repository.cam.ac.uk/server/api/core/bitstreams/e264602b-9423-47a2-95bb-6a5e6c63e925/content)

下调基因按相同逻辑保存，但只作为辅助模块，不与上调模块相减，也不进入主 UCell 分数。

3. **协同效应作为证据标签**

在 Media、LPS、CS、LPS＋CS 四组中另外拟合：

```text
expression ~ LPS + CS + LPS:CS
```

记录每个主基因的 `LPS:CS` 交互效应和 FDR。正向且显著的交互项说明该基因更像“联合刺激超过两个单独刺激简单叠加”的响应。

但交互项不作为主基因集的硬门槛，因为每组只有3个重复，统计效能有限，而且“非加和响应”本身也不等于 mitoxyperilysis。

4. **Torin-1 救援作为第二个证据标签**

比较 `LPS＋CS＋Torin-1 vs LPS＋CS`：

- 效应方向小于0：标记为方向性逆转；
- 同时 `FDR < 0.05`：标记为有统计支持的 Torin-responsive 基因；
- 可形成一个次要的 `Torin_reversed_up` 子集，用于敏感性评分。

该子集不能直接命名为“mTORC2特异执行基因”。Torin-1同时抑制 mTORC1 和 mTORC2；原研究对 mTORC2 的判断还依赖 RICTOR、RPTOR 等功能实验，而不是只靠 Torin-1 转录组。[Torin-1药理学研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2658096/)

5. **稳定性检查**

逐个剔除相关样本后重新拟合，记录：

- 三个主比较的方向是否保持；
- 交互效应方向是否保持；
- Torin-1逆转方向是否保持。

**审核结论**

这份 [ChatGPT Pro方案](C:/Users/14799/.codex/attachments/781c4511-34c6-4828-99f4-9266a021c654/pasted-text.txt) 有一些很好的增强点，但不能替换现有 F2。大致可以概括为：

- 约三分之一只能作为辅助分析；
- 约三分之一属于自创阈值或伪精确，应当删除。

现有 [F2主线](D:/服务器_胃癌线粒体亚群/胃癌MLMOD亚群主线研究方案.txt:402) 的基础更可靠：**作者三重比较定义主基因集，交互和Torin只增加证据，不决定成员资格。**

**主要问题**

1. **公开count表不能直接作为DESeq2主输入**

Pro方案说“不需要从FASTQ重新比对”，但F0已确认公开表约有 `5.85%` 小数，是合并后的RSEM expected-count-like矩阵，而且缺少每个样本完整的RSEM长度信息。

因此：

- 主路线仍应是 SRA → STAR/RSEM → tximport → DESeq2；
- 公开矩阵只能作为 `TMM + limma-voom` 的备用路线；
- 不能把公开小数矩阵直接或四舍五入后作为主DESeq2输入。

tximport官方也建议使用每个样本的RSEM结果，同时传递有效基因长度校正，而不是只把合并的expected counts交给下游模型。[tximport说明](https://new.bioconductor.org/packages/devel/bioc/vignettes/tximport/inst/doc/tximport.html)

2. **不应改成“交互项筛选主基因集”**

Pro方案用交互项FDR、`|log2FC|≥0.75`、至少两个比较 `|log2FC|≥0.5` 等条件建立 `MP_Synergy`。这些都是新设计的阈值，不是原论文标准，会改变我们刚确认的主基因集定义。

原作者明确使用三个比较的共同上调交集：每个比较均为 `log2FC>1、padj<0.05`。[原论文方法](https://api.repository.cam.ac.uk/server/api/core/bitstreams/e264602b-9423-47a2-95bb-6a5e6c63e925/content)

交互项可以保留，但只能回答：

> 联合处理效应在DESeq2的对数模型尺度上是否偏离两个单独处理效应的组合。

它不能直接证明生物学上的“协同致死”，也不能直接定义mitoxyperilysis。DESeq2中的交互项本质上是附加在主效应上的对数尺度项。[Bioconductor交互模型说明](https://bioconductor.uib.no/packages/3.22/workflows/vignettes/RNAseq123/inst/doc/designmatrices.html)

3. **rescue fraction公式不成立**

Pro方案定义：

```text
RF = |Torin效应| / |交互效应|
```

这两个效应不是同一个参照尺度：

- 交互效应是四组之间的差中之差；
- Torin效应是LPS＋CS＋Torin对LPS＋CS的直接比较。

用二者相除没有清楚的生物学百分比含义；交互效应接近0时还会造成比值不稳定，截断到1又会掩盖过度逆转。因此不采用 `RF≥0.30/0.50` 等规则。

改为保存两个直观标签即可：

- `torin_reversal_directional`：Torin比较的log2FC方向与主响应相反；
- `torin_reversal_supported`：方向相反且FDR<0.05。

此外，Torin-1同时抑制mTORC1和mTORC2，Torin逆转不能单独称为“mTORC2特异执行”。[Torin-1原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2658096/)

4. **243次分析会制造伪精确**

所谓243次 leave-one-replicate-per-group，是每组都删掉一个样本，只剩2个重复；这些组合高度重叠，并不是243次独立重复。

因此不采用：

- 80%、75%、70%等稳定率准入线；
- Core/Extended四套人为分层；
- “核心集至少15个基因”之类硬门槛。

保留简单的逐样本剔除分析即可，报告方向是否由某一个样本驱动，但不据此改写主基因集。

5. **“内部验证”实际是构建检查**

基因本来就是根据LPS＋CS高表达选出的，再在同一数据中证明其分数最高，带有必然性。这只能称为：

> 构建一致性检查或内部行为检查。

不能称为独立验证。使用一种bulk评分方法即可，建议 `singscore`；不需要同时堆叠singscore、GSVA、ssGSEA和edgeR敏感性。

6. **GSE235201可以纳入，但模型需要修改**

[GSE235201](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE235201) 确实可检验铁死亡和凋亡混杂，但其细胞系、时间点和处理组合并不完全平衡，不能简单拟合：

```text
Score ~ DeathCondition + CellLine + Time
```

更合适的是：

- 按 `cell line × time × experiment series` 分层；
- 每种处理与其匹配的DMSO或单药对照比较；
- 分别计算组内效应，再汇总方向；
- 不跨细胞系直接比较绝对分数；
- 明确它不能检验焦亡和坏死性凋亡。

它是**负对照证据**：如果评分在铁死亡和凋亡中也普遍升高，会削弱特异性；如果没有升高，只说明“不容易被这两类死亡替代”，不能单独证明mitoxyperilysis特异性。
