胃癌亚群方案
核心思路：通过单细胞多算法打分，将线粒体局部膜氧化损伤和胃癌发生和进展建立联系，筛选识别核心基因，进行进一步生信分析
数据准备：
单细胞数据：GSE183904 （对照/原发/腹膜转移）等
Bulk数据（带预后信息）：TCGA / GSE15459 / GSE66229 / GSE84426/ GSE26253等
F1 单细胞分析常规流程： TSNE/UMAP图 （细胞注释前后等不同分组绘图），Marker表达点图/Feautureplots等，细胞比例柱状图等，用InferCNV鉴定恶性细胞的常规流程【至少6个图】
F2 单细胞通路打分：
通路基因选择：线粒体局部膜氧化损伤的热点。Addmodulescore / AUCell / ssGSEA / singscore/ Ucell等算法打分，取结果的平均值，(分析分析疾病和对照的肿瘤上皮细胞的差异)。【8张图左右】
寻找高线粒体局部膜氧化损伤活性亚群
F3 分析预后特异性亚群功能： KEGG+GO+打分富集分析+拟时序分析等 【至少4个图】
F4 细胞通讯： Cellchat分析 分析预后不良特异性亚群与外界细胞的交互特征，网络图，气泡图，层级图，互作图等【8张图左右】
F5进一步筛选标志物：基于Bulk数据，筛选关键基因分析：【预后KM曲线】【TNM分期】【转移】【疾病对照表达水平差异】【创新性】等指标，进一步分析基因的重要性。【至少6张图】
F6+F7 免疫/富集/突变： Cibersort/ MCP-count/ ESTIMATE等肿瘤常见算法识别基因免疫浸润差异，绘制热图/箱子图/相关性图。分析TIDE/ IPS评估基因和免疫治疗的关系箱子图。 KEGG/GO/ GSEA分析及基因相关通路【14张图左右】
F8 单基因单细胞：
单细胞：虚拟敲除 / Featureplot表达分析 / 细胞通讯可以根据单基因是否表达/表达中位数，画网络图/点图/互作图，探究基因在细胞表达和通路之间的关系 【至少8张图】
如遇到算法不合适/结果不符合预期使用其他算法/工作量替代。
